# SAI
SAI开源项目，有以下主要功能 1.AI对话（模型为deepseek） 2.AI在线搜索（模型为秘塔AI） 3.AI生成图片和视频（模型为Seedream-4.0，Grok-2-Image和Doubao-Seedance-1.0-pro） 4.AI在线生成文档并可编辑（ deepseek+使用的CKEditor 框架开源富文本编辑器框架） 5.3D全景卫星地图功能（使用了百度地图实现） 注意： 1.需要您自己申请相关apikey才能使用 2.该项目为纯前端项目，所有的后台都是接入的第三方APIKEY 3.该项目主要以vue3+JS开发，但是也接入了TS，但大部分页面还是vue3开发，有部分页面使用了TS，您可以自主选择，如果您TS不是很熟，也可以拉下来后只使用js开发
