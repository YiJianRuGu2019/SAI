# SAI

SAI 开源项目，技术栈为 vue3+ts，大部分页面是用 js 写的，ts 不是很熟练的朋友也可以放心使用，有以下主要功能 1.AI 对话（模型为 deepseek） 2.AI 在线搜索（模型为秘塔 AI） 3.AI 生成图片和视频（模型为 Seedream-4.0，Grok-2-Image 和 Doubao-Seedance-1.0-pro） 4.AI 在线生成文档并可编辑（ deepseek+使用的 CKEditor 框架开源富文本编辑器框架） 5.3D 全景卫星地图功能（使用了百度地图实现） 注意： 1.需要您自己申请相关 apikey 才能使用 2.该项目为纯前端项目，所有的后台都是接入的第三方 APIKEY 3.该项目主要以 vue3+JS 开发，但是也接入了 TS，但大部分页面还是 vue3 开发，有部分页面使用了 TS，您可以自主选择，如果您 TS 不是很熟，也可以拉下来后只使用 js 开发
注意： 1.所有的 key 都是在 api/apiKey.js 中配置的，您需要自己申请相关的 key 才能使用 2.头部导航栏的菜单是用的腾讯地图，3D 地图是用的百度地图 3.使用生成哪里使用自己放视频链接且可 htts 访问才能在公网展示
